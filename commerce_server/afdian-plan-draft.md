## 后台和服务端对应关系

1. 账号持有人已完成手机绑定和创作者申请；方案已创建，真实 `plan_id` 仅在爱发电后台或服务端配置中取用。不要把 API Token 或 OAuth client secret 写入仓库。
2. 服务端配置 `AFDIAN_PRO_PLAN_ID=<该方案 ID>`、`AFDIAN_PRO_AMOUNT_MINOR=3000`。现有核验要求成功的常规方案订单、精确实付金额和 OAuth 用户 ID 一致。测试夹具中的 4900 仅是虚构金额，不决定正式定价。
3. 上线前增加对年费订单 `month`/方案有效期的真实样本核对；现有原型只要求 `month > 0`。如实际年费方案订单字段不同，应按平台真实响应调整校验，再用小额受控真实订单联调。
4. Webhook 地址拟为 `https://<自有域名>/v1/webhooks/afdian`，OAuth 回调拟为 `https://<自有域名>/v1/auth/afdian/callback`。只有 HTTPS 域名和服务端正式就绪后才在后台填写。
5. 爱发电开发者后台可提供创作者 `user_id`、API Token 与 Webhook 设置；OAuth `clientID`/`clientSecret` 需按官方流程向平台申请，提供应用名称和可信域名。[开发者 API 文档](https://guide.afdian.com/creator/developer) · [OAuth2 文档](https://guide.afdian.com/creator/oauth2)
