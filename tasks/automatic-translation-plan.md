# 自动内容翻译（2026-11-18）

用户要求：新增自动译中文／其他语言开关，自动翻译搜索结果标题与详情简介，保留原文，整批完成后统一测试，无付费限制。

- 设置与搜索页均提供“自动翻译”入口。默认关闭，目标语言默认中文，可选 ML Kit 支持的其他语言。
- 使用随包附带的 ML Kit 语言识别模型判断原文语言；不支持或无法识别时显示可重试状态并保留手动入口，不猜测专有名词。
- 原文始终保留，译文单独展示并标注语言与机器翻译。搜索词与中英译日功能保持原行为。
- 搜索网格只翻译可见项，详情标题与简介也按可见性触发；单任务队列、缓存优先，离屏、关闭开关、切换语言或页面时取消旧任务并避免旧译文串入新内容。相同目标语言不重复翻译。
- 目标语言和自动开关进入现有设置备份；移动数据下载许可仅本机保留。默认只允许 Wi-Fi 下载缺失模型，允许移动数据需用户主动选择。模型齐备后可离线翻译。
- 复用 150 条／1 MiB 内容缓存，按原文、源语言模式和目标语言区分；手动和自动翻译都支持当前目标语言。已启动的 SDK 模型下载可能在取消后继续完成，但不继续翻译或发布过期结果。
- 整批实现后统一执行单元、编译、模拟器 UI、取消／切换／缓存、设置持久化与真实模型验证。最初仅验证 debug；后续按用户明确要求构建并覆盖安装真机 release。

依据：Google 官方 ML Kit Android 语言识别和翻译文档。
